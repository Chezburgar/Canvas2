How to get your Canvas Access Token
  1. Open Canvas (mcpsmd.instructure.com)
  2. Click your avatar → Account → Settings
  3. Scroll to "Approved Integrations"
  4. Click + New Access Token
  5. Enter purpose: "Canvas2", click Generate
  6. Copy the token and paste it below
Important Notice

Canvas2 is an experimental project created by an external developer. This project is unofficial and has a long way to go before it is anything close to perfect. The goal with this project is to greatly improve the user experience and while we have achieved that we are still unofficial. Even if it works we strongly don't recommend completing assignments/quizzes on Canvas2 as your organization may disapprove of it being unofficial.
